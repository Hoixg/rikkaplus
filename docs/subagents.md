# 子代理

移植来源：[xiaoyuili/Yuihub，056b4c164e1c8742117926b20a1be59114c1f5fa](https://github.com/xiaoyuili/Yuihub/blob/056b4c164e1c8742117926b20a1be59114c1f5fa/app/src/main/java/me/yui/yuihub/data/ai/tools/SubagentTools.kt)，沿用本项目的 AGPL-3.0 许可。工具定义和抽屉体验基于上游；运行器适配 RikkaPlus 的 GenerationLoop、会话缓存、消息队列和后台服务。

## 使用

在助手设置 → 本地工具开启「启用子代理」。每个助手单独保存，旧助手及新助手默认关闭；本轮模型必须支持工具调用。主代理在 `prompt` 中直接写明分析、实现或检查任务的上下文、约束和交付要求，无需配置角色。

主模型可调用：

| 工具 | 参数 | 返回 |
| --- | --- | --- |
| `spawn_agent` | `description`, `prompt`；可选 `async`, `timeoutMs`, `maxToolCalls` | 同步返回子代理结果；异步立即返回 `status=running`, `taskId`, `description`, `hint` |
| `followup_agent` | `sessionId`, `message` | 同步继续同一子会话，复用创建时的实际模型及执行配置 |
| `poll_agent` | `taskId` | 运行时返回耗时、工具调用数和最近动作；终态返回状态、会话 ID 及 `result`（完整子结果 JSON 字符串） |
| `cancel_agent` | `taskId` | 返回 `cancelling`，随后通过轮询查看终态；保存已有轨迹 |
| `list_agents` | 无 | 当前父会话的同步及异步任务、状态、耗时与句柄到期时间 |

结果沿用上游的 `status`, `description`, `sessionId`, `startedAt`, `endedAt`, `durationMs`, `files`, `toolCallsDetail`（按工具名聚合的 `name`/`count`）；空输出时保留字符串 `toolCalls` 摘要。另提供 `toolCallCount` 和失败时的已有文本，便于显示及恢复。

子会话可直接聊天：复用普通聊天的输入、消息编辑、重新生成、审批、复制与导出，也可由主会话调用 `followup_agent` 继续。直接聊天与 Yuihub 一致，使用所属助手的普通聊天配置及子会话保存的模型和工作区。子会话可单独切换模型，选择保存到该会话；流式输出和旧保存快照保留最新模型选择。主代理工具追问仍复用创建时的执行配置。普通会话、文件夹和最近会话列表只列出父会话。

抽屉与 Yuihub 一致：父会话行右侧箭头展开/收起，展开后显示缩进的子会话标题与运行竖条，点击打开、长按删除；不额外显示“子代理”标题区或常驻删除按钮。打开子会话时自动展开所属父会话。

## 执行约束

- 子任务使用独立消息历史，继承父会话本轮实际生效的模型、助手配置、工作区及可用工具，包括模型原生工具；会话级系统提示词不会覆盖子代理执行限制。
- 全局最多执行四个子任务。超出数量等待空位，等待时间计入超时。连续的创建/追问工具调用并行执行，普通工具仍按顺序执行，结果按原调用顺序回填。
- 同一子会话的生成串行进行：子任务执行期间直接发送的消息留在队列，结束后继续；用户聊天或待发送队列已占用时，工具追问返回 `AGENT_SESSION_BUSY`，不会取消用户生成或覆盖历史。跨父会话的查询、取消及追问均返回找不到任务/会话。
- 自动子任务禁止继续派生子代理、询问用户、申请目录授权和修改共享 MCP/技能/定时任务管理配置。工具在准备真实参数后检查审批需求，需审批时返回错误，请主代理执行；保留原有命令拦截及执行期限。`maxToolCalls` 同时限制实际调用数量，防止单个工具批次突破上限。用户直接聊天使用普通审批流程，子会话仍不能派生子代理。
- 正常结束主会话允许异步子任务继续，其后台服务租约独立保留。停止、删除或迁移父会话先阻止新生成，取消并等待子任务保存轨迹，再删除或调整归属。定时任务等待其子任务完成，共享该次运行的剩余期限。
- 子任务成功、失败、取消和超时都会保存已有轨迹并释放后台资源。运行句柄在结束后保留 30 分钟；数据库中的轨迹长期保留。重启后不恢复运行句柄，不自动重跑子任务。
- 结果最多内联 2,000 字符（包含截断提示），超过部分全文保存至 `/tool_outputs/<sessionId>.md`。文件快照只扫描继承工作区，限制为深度 6、最多 5,000 条目，并排除 `.git` 与越界符号链接；不扫描其他工作区。

## 数据与验证

数据库 34 → 35 使用显式迁移，在原表上增加 `parent_conversation_id` 和索引，保留消息、定时任务及其运行记录、压缩检查点、文件夹等现有字段。避免 Room 生成的重建会话表迁移触发消息外键级联删除。父子关联进入实体转换及备份；会话树删除通过 ChatService 等待写入收尾，持久化层清理子轨迹、消息和搜索索引。迁移助手时父子归属在同一数据库事务中更新。
