### AI 手机操作

- 新增应用内无障碍手机操作工具，支持读取界面、截图、点击、输入、滑动、系统导航和打开应用。
- 手机操作提供独立开关，修改界面默认需要审批；按会话隔离界面快照，操作前重新校验目标。
- 改进前台窗口、键盘和系统弹窗识别，补充控件提示、勾选及选中状态，支持方向滚动和键盘搜索、发送、完成操作。
- 输入后核对内容，操作后等待界面变化；短暂读取不到控件时仅重试读取，不自动重复点击或输入。

### 工作区与后台命令

- SSH 工作区支持跳板机，分别确认跳板机和目标主机的密钥，凭据继续加密保存。
- 支持后台运行 Shell 命令、查看任务状态和日志，并将完成通知送回所属聊天。
- 后台命令适配共享及独立 Linux 环境，重装环境时只停止对应环境的命令。
- 在「数据设置 → 存储管理」提供旧环境清理，保留当前使用的共享环境、独立环境、SSH 和项目文件；修复无权限目录导致检测中断的问题。

### 聊天与插话

- 待发消息增加「取消」，移回输入框并覆盖已有草稿，同时恢复文字和附件；保留三点长按排序、编辑和删除。
- 聊天顶栏增加会话菜单，支持消息概览、导出和删除；消息概览支持左滑进入。
- 会话导出支持保存为文件，世界书条目支持拖动排序。
- 删除聊天或消息时同步清理对应收藏，修复收藏模型重复导致的闪退。

### MCP 与定时任务

- MCP 顶部设置统一管理 AI 管理开关和免审批操作，查看、新增、编辑、删除配置默认逐次审批；服务工具的审批规则独立保留。
- 精简定时任务界面，移除列表中的提示词预览，完整内容在编辑页查看。
- 定时任务等待会话收件箱和上下文压缩完成后再开始执行。

### 性能与显示

- 缓存历史图片的压缩结果，减少连续对话和工具调用时重复编码。
- 修复紧贴标点或中文的行内公式，以及单个波浪号删除线的渲染问题。
- 同步模型搜索、模型目录定期刷新、POST 余额查询及本地网络权限提示等上游改进。

### 安装说明

- 提供一份包含 ARM64 和 x86_64 的 GitHub Release 通用 APK，可覆盖安装同签名正式版并保留数据。
- 手机无障碍权限仍需手动开启；键盘提交和截图需要 Android 11 及以上系统。
