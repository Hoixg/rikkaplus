## 新增

- 定时任务：在「扩展管理 → 定时任务」创建、编辑和管理任务，支持单次、每天、每周和固定间隔执行。
- 任务可自定义执行提示词、助手、模型和结果通知，支持新建聊天、继续聊天及复制指定消息重新生成。
- AI 可按用户明确要求创建和管理当前助手的定时任务，写操作使用普通审批；定时执行期间仅可查询任务，避免递归创建或触发任务。
- Shizuku：在扩展管理中独立授权和检查状态，让 AI 使用已运行的 Shizuku 服务执行命令。
- Shizuku「执行前审批」开关：默认开启，关闭后可直接执行命令，适用于已授权的聊天及定时任务。

## 优化

- 定时任务编辑入口更明确，配置集中展示；长提示词在输入区域内滚动，修改审批仅展示新配置。
- 支持任务运行期间编辑后续配置，本次执行保留原有快照；执行记录保存实际使用的模型。
- 增加「后台运行与权限」入口，集中管理通知、精确闹钟、电池优化和厂商后台设置。
- Termux 的受管终端会话和后台任务可跨聊天共用，保留命令完成状态、退出码、输出读取和任务管理能力。
- 每次仅构建并提供一份 ARM64 / x86_64 通用安装包，构建与发布流程同时检查安装包数量及架构。

## 修复

- 修复停止生成后立即发送消息，消息队列可能再次被暂停的问题。
- 修复 Release 构建中全局排除 Kotlin 反射库，导致账号登录回调所需的 Ktor 依赖缺失、R8 构建失败的问题。
- 开发版发布会自动清理以往遗留的分架构和其他安装包附件，避免同一页面出现多个安装包。

## 使用说明

- 本版本包名为 `io.github.hoixg.rikkaplus`，使用 `1.0` 分支独立签名，与历史 custom 版及 Debug 版分别安装。
- 自动执行定时任务需授予精确闹钟权限，并按手机系统要求允许后台运行。
- Termux、Shizuku 需要各自安装、配置并授权；系统杀后台仍可能影响任务，当前没有自动拉起或自动重启 Shizuku 服务的功能。
