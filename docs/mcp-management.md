# AI 管理 MCP

在 MCP 列表页点击顶部的设置按钮，打开「MCP 设置」。AI 管理和免审批开关放在同一面板中，列表仅展示服务。

「允许 AI 管理 MCP」默认关闭，沿用原有开关状态。开启后提供查看配置、新增服务、编辑服务和删除服务四类操作，默认每步都需用户审批。新增和编辑继续共用配置工具，根据是否提供服务 ID 分别判断审批策略。

「免审批」默认关闭。开启后可分别选择查看、新增、编辑、删除，只有选中的管理操作可直接执行；空选或未知选项不会放行任何操作。关闭免审批会保留选择，再次开启时复用。关闭 AI 管理后，既有工具也不能继续访问或修改配置。

审批沿用聊天的工具审批、拒绝与恢复流程；待审批的配置操作不会提前执行。策略在每次判断时读取最新设置。设置保存在现有 DataStore 中并随应用设置备份，无需修改聊天数据库。

此处仅控制 AI 管理 MCP 配置。各 MCP 服务内部工具的启用和审批设置继续由其服务详情页管理。查看配置仍不返回请求头值或 OAuth 密钥，配置工具也不能修改审批策略。
